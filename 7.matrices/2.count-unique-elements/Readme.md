Input Format

The first line contains two integers, m and n, separated by a space.

The next m lines each contain n integers, representing the matrix.

Constraints

1 ≤ m, n ≤ 100

1 ≤ Matrix[i][j] ≤ 1000

Output Format

Print the count of different elements in the matrix.

2 5 3 3
7 8 2 9
5 10 7 10
Sample Output 0

7

3
